# v1.0 Integrated-Training Verification

Design checkpoint `2819e7d0e4c1b06b273f3fb912b525f7bf7d8a7f` was verified on
`feature/v1.0-integrated-training` against `v0.4-error-recovery`. The evidence
boundary is SystemVerilog simulation in Questa and FPGA implementation in
Quartus; it is not ASIC, PHY, BER, electrical, or UCIe compliance evidence.

## Questa

Questa Intel Starter FPGA Edition 2023.3 passed a dedicated production-mode
UVM campaign with `ALLOW_ABSTRACT_DATATRAIN_BYPASS=0`. Seeds
1701/1802/1903/2004/2105 each ran 36 trials (180 total). Each seed guarantees
all nine scenario classes before randomized repetition: nominal pass,
failed-pattern retry/pass, START retry, malformed START, END retry, malformed
END, reset abort, fatal abort, and state-timeout abort. Abort/fault phase,
transmit backpressure, response latency, receive-valid gap, corrupt lane count,
and threshold were generated with seeded `$urandom_range`.

The predictor and scoreboard check message order, phase gates, independent
23-bit lane-LFSR progression, strict threshold result, failed-run residency,
END suppression on failure, exact DATATRAINVREF advance, retained error cause,
and sequencer/training abort. Explicit sampled bins report scenario, phase,
gap, corruption, and outcome-by-gap totals in each seed log. Starter licensing
does not support the intended class-randomize/covergroup flow, so no UCDB
percentage is claimed.

Fresh regression closure:

- five directed suites;
- nine deterministic UVM tests;
- 200 sideband randomized trials;
- 160 legacy training randomized trials;
- 180 recovery randomized trials;
- 180 production integrated-training randomized trials.

All completed with zero UVM errors/fatals and no assertion failures. Raw logs
and simulator databases are intentionally ignored.

## Quartus

Quartus Prime Lite 23.1std.1 targeted Cyclone 10 LP
`10CL025YU256C8G` with the 12.500 ns (80 MHz) clock constraint.

The reusable wide-pin core synthesized successfully (786 synthesized logic
cells) but, as expected, did not fit: 149 user I/O pins require more than the
144 general-purpose pins available. The practical `ucie_ltsm_fpga_wrapper`
completed synthesis, fitting, assembly, and timing with zero errors:

| Metric | Result |
|---|---:|
| Logic elements | 824 / 24,624 |
| Registers | 505 |
| Physical pins | 119 / 151 |
| Slow 85 C setup WNS / TNS | +1.013 ns / 0.000 ns |
| Slow 85 C hold WNS / TNS | +0.435 ns / 0.000 ns |
| Fast 0 C setup WNS / TNS | +7.537 ns / 0.000 ns |

The design is not fully constrained for board-level setup/hold because pin
locations and external I/O delays are absent. Other retained warnings are
constant upper message bits, unused CSR write-data bits, the existing
parameter-width truncation warning, and the Lite LogicLock limitation.
